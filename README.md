# PRT563 Assignment 4 - Danala 11

## Project
Graph Database Implementation and Analytics using Neo4j.

This project migrates a relational online ordering and delivery database into Neo4j and demonstrates graph queries and graph analytics.

## Repository Contents

- `import.txt` - Cypher scripts for graph database implementation
- `queries.txt` - Cypher scripts for Task 3 queries
- `csv/` - CSV files used to construct the graph database
- `analytics/` - Centrality and similarity analysis scripts
- `evidence/` - Screenshots showing successful execution and results
- `diagrams/` - Graph modelling diagrams
- `validation/` - Database validation files

## Final Database

- Nodes: 140
- Relationships: 170
- Pickup Orders: 10
- Delivery Orders: 10
- Invalid Order Subtypes: 0
